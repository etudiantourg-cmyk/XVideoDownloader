# X Video Downloader

تطبيق Android أصلي بزر عائم لفتح واجهة إدخال رابط منشور X.

## الحالة الحالية
هذه نسخة تأسيسية: واجهة عربية، صلاحية الظهور فوق التطبيقات، وزر عائم قابل للتحريك مع قراءة رابط X من الحافظة. **محرك استخراج وتنزيل الفيديو غير مكتمل بعد**؛ لا تعتبر هذه النسخة تطبيق تنزيل نهائياً.

## البناء
يفتح المشروع في Android Studio أو شغّل GitHub Actions من تبويب Actions. ينتج ملف APK تجريبي (debug).

يدعم Android 6.0 فأحدث. يتطلب منح صلاحية الظهور فوق التطبيقات يدوياً.

## ملاحظات
يقتصر الاستخدام على المحتوى العام الذي تملك حق تنزيله. لا يدعم المنشورات الخاصة أو المحمية، وقد تتغير آلية الوصول إلى وسائط X.
