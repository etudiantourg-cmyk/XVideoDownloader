# X Video Downloader

تطبيق أندرويد بواجهة عربية وزر عائم قابل للتحريك لتنزيل ملفات الفيديو MP4 المتاحة علناً من منشورات X.

## الوظائف الموجودة
- زر عائم يظهر فوق التطبيقات بعد منح إذن الظهور فوق التطبيقات.
- اكتشاف رابط X من الحافظة، كما يقبل التطبيق الروابط المرسلة إليه عبر قائمة المشاركة.
- استخراج خيارات MP4 والجودات المتاحة عبر واجهة FxTwitter API v2.
- اختيار الجودة ثم بدء التنزيل بواسطة Android DownloadManager مع إشعار النظام.
- حفظ الملفات في مجلد Movies/XVideoDownloader.

## متطلبات التشغيل
- Android 6.0 أو أحدث.
- اتصال بالإنترنت.
- إذن الظهور فوق التطبيقات.
- على Android 9 وما قبله: إذن التخزين لحفظ الملف في مجلد Movies العام.

## بناء APK
يعمل سير GitHub Actions عند كل تحديث على فرع main أو عند تشغيله يدوياً:
1. يجهز Java 17 وGradle.
2. ينفذ assembleDebug والاختبارات.
3. يرفع APK باسم XVideoDownloader-debug في Artifacts.

افتح تبويب Actions في المستودع، ثم افتح أحدث تشغيل ناجح ونزّل Artifact باسم XVideoDownloader-debug. ملف APK داخل ZIP.

## حدود مهمة
- التنزيل متاح فقط للمنشورات العامة التي تعرض روابط MP4 مباشرة عبر خدمة المصدر.
- المنشورات الخاصة/المحمية، أو التي لا توفر ملف MP4 مباشر، لا يمكن تنزيلها.
- تعتمد عملية استخراج البيانات على FxTwitter API وخدمات X/CDN؛ قد تتغير الاستجابة أو تتوقف الخدمة، لذلك لا يمكن ضمان عمل كل رابط دائماً.
- لا يرفع التطبيق ملفاتك أو ينشئ حساباً. عند استخراج رابط، يرسل رقم المنشور إلى FxTwitter API؛ ويرى مزود الخدمة عنوان IP وطلب الشبكة كأي خدمة ويب.
- نزّل فقط المحتوى الذي تملك حق تنزيله أو لديك إذن صاحبه.
